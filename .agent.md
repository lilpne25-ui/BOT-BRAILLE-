## Reglas no negociables

1. No mezclar código, datos, secretos, branding, despliegue o historial Git con Braille International.
2. No romper flujos existentes para introducir mejoras visuales o refactors.
3. No ejecutar `npm run db:setup`, `prisma db push --force-reset` ni seeds destructivos sobre datos operativos.
4. No subir `.env`, SQLite, contraseñas, tokens, cookies, claves webhook, QR, backups ni perfiles de navegador.
5. Web/bot puede crear o actualizar prospectos, pero no generar ni enviar cotizaciones automáticamente.
6. Mantener revisión humana para cotizaciones.
7. No dejar controles visuales que parezcan funcionales si no tienen comportamiento real.
8. Operaciones destructivas deben tener permisos, preview de impacto, confirmación y auditoría.
9. Antes de terminar cualquier cambio ejecutar:

```bash
npm run lint
npm run test
npm run build
```

10. Actualizar documentación y screenshots cuando cambie de forma material la UX, arquitectura, seguridad o integración.
