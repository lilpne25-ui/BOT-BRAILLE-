# Logo de Braille International

Coloca aquí el archivo del logo con el nombre exacto:

```
logo-braille.png
```

En cuanto el archivo exista en esta carpeta (`public/logo-braille.png`), tanto el PDF del bot de WhatsApp como el del cotizador manual lo van a usar automáticamente en el encabezado — no requiere ningún cambio de código adicional. Si el archivo no existe, ambos PDF siguen funcionando igual, solo que con el nombre "Braille International" como encabezado de texto en vez del logo.

Recomendación: PNG con fondo transparente, altura aproximada de 200-400px para que se vea nítido al reducirlo en el PDF.
