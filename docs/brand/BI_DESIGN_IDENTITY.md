# Identidad visual BI DESIGN aplicada al CRM

## Paleta

- Azul principal: `#1B9CD9`
- Naranja/acento: `#EB5B28`
- Ink/dark: `#202D36`
- Navy: `#191E39`
- Gris: `#CDCCCC`

## Aplicación en CRM

- Azul: acciones primarias, navegación activa, gráficas.
- Naranja: acentos, CTA destacados, guías y separadores.
- `#202D36`: texto principal y superficies oscuras.
- `#191E39`: hero/login y fondos premium.
- Gris: bordes y elementos secundarios.
- Verde se mantiene únicamente como color semántico de éxito, no como color de marca BI DESIGN.

## Logo

Assets generados desde el brand sheet proporcionado:

```text
/public/brand/bi-design-logo-full.png
/public/brand/bi-design-mark.png
```

Se utilizan en:
- Login.
- Sidebar.
- Metadata/favicon.
- Cotizaciones/PDF.

## Componentes visuales

- Login de dos columnas.
- Hero oscuro con azul+naranja.
- Sidebar con marca real.
- Dashboard BI DESIGN.
- Cotizador y PDF con identidad BI DESIGN.
- Variables CSS por instancia para poder desplegar una segunda instancia de Braille International.
