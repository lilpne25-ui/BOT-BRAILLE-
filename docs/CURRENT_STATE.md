# Estado actual — BI DESIGN CRM

Fecha de snapshot: **2026-08-11**.

## Módulos operativos

### Dashboard
Indicadores reales, alertas, próximas acciones y actividad reciente.

### Prospectos
Alta, edición, responsable, estado, valor, próxima acción, actividad, integración con cotizador y eliminación administrativa en cascada.

### Cotizador
Flujo guiado de 4 pasos, borradores, folio persistente, PDF y estados comerciales. Revisión humana obligatoria.

### Catálogo
Precios base, multiplicadores/materiales y auditoría.

### Proyectos
Alta/edición, responsable, estado, avance, riesgo, instalación, evidencia y relación con cotización aceptada.

### Garantías
Vigencia, responsable, mantenimiento, actividad y seguimiento.

### Usuarios y permisos
Roles base, permisos granulares, altas/edición/desactivación/eliminación con restricciones.

### WhatsApp
Módulo técnico/piloto. Baileys no debe tratarse como canal productivo definitivo.

### Integración Web
Webhook dedicado con autenticación, validación, normalización, deduplicación/idempotencia, origen WEB, revisión humana y sin cotización automática.
